# Machine Learning Practice

This repository contains two machine learning projects completed as part of my university practice.

## Projects

### 1. AutoML Salary Prediction

In this project, I used AutoML frameworks to predict football players' salaries.

The target variable is `wage_eur`.

Two frameworks were used:

- AutoGluon
- H2O AutoML

The models were evaluated using regression metrics such as R², RMSE and MAE.

Main tasks:

- data preparation;
- model training;
- comparison of AutoML models;
- prediction evaluation;
- error analysis;
- feature importance analysis.

Notebook:

`Auto_ML.ipynb`

---

### 2. Image Classification and Fine-tuning

In this project, I worked with an image classification model for cats and dogs.

The work included:

- training and fine-tuning the model;
- evaluating model accuracy;
- checking for overfitting;
- analyzing classification errors;
- finding incorrectly labeled images;
- building a simple application for image classification.

Notebook:

`ML-FT.ipynb`
